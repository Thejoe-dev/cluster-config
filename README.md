# Cluster Services

This repository contains configurations for Kubernetes clusters, including installation and management of key services.

## Installed Services
- **NGINX**: Used as an ingress controller for routing traffic within the cluster.
- **Prometheus**: Set up for monitoring cluster performance and resource usage.
- **Grafana**: Provides dashboards for visualizing monitoring data from Prometheus.
- **Flux**: Automates continuous delivery and GitOps workflows.

## Usage
Clone the repository, configure your Kubernetes cluster, and apply the configuration files to set up services.
